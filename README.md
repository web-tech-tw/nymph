# Nymph

Nymph 是一個由 AI 驅動的多功能自動化機器人，旨在協助自動化資源管理、活動監控以及提供即時支援。

![Nymph Avatar](avatar.png)

## 主要功能

* **多平台整合**：支援 Line, Discord 的訊息監聽與串接。
* **AI Agent 核心**：整合 Anthropic Claude，提供智慧對話功能。
* **對話記憶**：基於 MongoDB 儲存對話歷史，支援語境理解。
