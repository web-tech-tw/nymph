# Nymph (寧芙)

Nymph 是一個由社群驅動的資深技術顧問智慧體，專為臺灣網際網路技術推廣組織（Web Tech TW）與開發者社群打造，提供專業、深入且具脈絡的架構諮詢與技術疑難排解支援。

![Nymph Avatar](avatar.png)

---

## 核心特色與能力

* **資深技術架構顧問**：以先進的大型語言模型為思考核心，能針對前端、後端、系統架構、資安通訊與 DevOps 疑難提供具體且深度的建議。
* **MCP (Model Context Protocol) 智慧工具擴充**：
  * 原生支援開放的 MCP 工具協議，讓 Nymph 不僅能進行語言交流，更能主動調用各類外部工具與專案自訂服務。
  * **主動調用與動態整合**：面對複雜問題時，Nymph 能在對話過程中自主判斷並調用相應的 MCP 工具（如即時資訊查詢、資料庫檢索、外部 API 調用等），為你提供超越純文本模型的精準解答與即時協助。
* **社群工程知識庫檢索**：內建社群歷史技術沉澱與解決方案資料庫，可即時檢索過往的除錯筆記、架構決策與常見技術陷阱。
* **流暢的多輪對話記憶**：具備長期對話脈絡理解能力，能在多輪討論中持續追蹤問題細節，無需重複提供背景資訊。
* **多平台無縫接入**：常駐於 Discord 與 LINE 等社群平台，隨時隨地為開發者提供即時協助。

## 如何與 Nymph 互動

### 在 Discord 中
* **頻道討論**：在已加入 Nymph 的頻道中直接 `@Nymph`（或標註寧芙）並提出你的問題。
* **私人諮詢**：直接發送私訊 (DM) 給 Nymph 進行一對一深度技術討論。

### 在 LINE 中
* 在社群或官方帳號中直接發送訊息，Nymph 將自動辨識語境並進行回覆。

## 常見使用情境

1. **技術選型與架構諮詢**
   > *「我們想在大型專案中評估微前端與 Monorepo 架構，有什麼具體優缺點與實務建議？」*

2. **問題排查與錯誤診斷**
   > *「在 Docker 容器內編譯 native 模組時出現 node-gyp 報錯，這可能的原因與解法是什麼？」*

3. **調用 MCP 延伸工具**
   > *「幫我查詢目前最新的社群工程文件，看看上次關於認證架構的決策紀錄。」*

4. **網路協定與資安觀念**
   > *「請說明 HTTP/2 與 HTTP/3 在連線多工與壅塞控制上的核心差異與升級考量。」*
